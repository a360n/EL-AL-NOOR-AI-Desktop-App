# منظومة EL AL-NOOR AI ☀️🤖 - تطبيق الفحص المكتبي (Windows Desktop App)
> **تطبيق مكتبي متكامل لأتمتة فحص وتحليل جودة الألواح الشمسية بالذكاء الاصطناعي وقواعد البيانات**
> **معمل النور للألواح الشمسية (Al Noor Solar Panels Factory)**

---

## 📌 نبذة عامة (Overview)

تم بناء وتطوير هذا التطبيق المكتبي ليعمل مباشرة على بيئة **Windows** (ويمكن تشغيله كملف `.exe` مستقل أو بنقرة واحدة عبر `run_app.bat`).
يقوم البرنامج بمراقبة المجلد المشترك لجهاز الفحص **Ecolab EL HR** الصادر من برنامج `EcolabEL.exe (v3.17.2)`، وتنفيذ دورة الفحص والمعالجة الكاملة بشكل آلي ولحظي:

1. **استقبال ومراقبة الملفات**: التقاط أزواج الملفات الفريدة فور حفظها (`.el` و `.tif`).
2. **قراءة وتحويل ملف الـ EL**: استخراج بيانات التشخيص المرجعي وتوليد ملف `info.json`.
3. **التقطيع الدقيق (144 خلية)**: تطبيق نفس خوارزمية التقطيع المعتمدة في `el_cropper_app` (التي تدرب عليها نموذج الذكاء الاصطناعي) بدقة $224 \times 224$ بكسل مع هوامش الأمان بنسبة 15%.
4. **الاستدلال بالذكاء الاصطناعي**: تمرير الـ 144 خلية دفعة واحدة عبر نموذج `EfficientNet-B0` (بدقة 99.8%) لتصنيف كل خلية واستخراج درجة الثقة وتوليد ملف `aiinfo.json`.
5. **إعادة التركيب والتظليل المقارن**: توليد صورتين مجمعتين بدقة عالية:
   - **الصورة الأولى (Human Ground Truth)**: معلم عليها بعلامة `X` وإطار أحمر على مواقع الخلايا المعيبة وفق `info.json`.
   - **الصورة الثانية (AI Diagnosis)**: معلم عليها بعلامة `X` وإطار ودرجة الثقة وفق `aiinfo.json`.
6. **التخزين في قاعدة بيانات SQL**: حفظ السجلات والمسارات وقرارات المشغلين وإحصائيات التدقيق في قاعدة بيانات SQLite مدمجة.
7. **الواجهة الرسومية التفاعلية**: واجهة مكتبية سريعة وحديثة بهوية معمل النور تدعم التبديل بين اللغتين (العربية والإنجليزية)، ومقارنة الصورتين جنباً إلى جنب مع تحكم كامل بالتقريب (Zoom & Pan)، وأزرار الإقرار (مطابق / غير مطابق مع نافذة تصحيح يدوي بمصفوفة 144 خلية تفاعلية)، وسجل الفحوصات، وسجل تدقيق AI، وإدارة المشغلين، ومحاكي بث العينات.

## 🚀 طريقة التشغيل الفوري (How to Run)

### 1. على نظام Windows (بنقرة واحدة):
- انقر نقراً مزدوجاً على الملف: **`run_app.bat`**
- سيبدأ التطبيق فوراً ويفتح النافذة المكتبية المستقلة.

### 2. عبر سطر الأوامر (Command Line / Terminal):
```bash
# تثبيت المتطلبات (مرة واحدة فقط)
pip install -r requirements.txt

# تشغيل التطبيق
python main.py
```

---

## 📦 طريقة تجميع التطبيق إلى ملف تنفيذي (.exe)

لإنشاء ملف تنفيذي مستقل (`EL_ALNOOR_AI.exe`) لنظام Windows:
```bash
python build_scripts/build_exe.py
```
سيتم إنشاء حزمة التطبيق المكتبي بالكامل داخل المجلد:
`EL_ALNOOR_AI_App/dist/EL_ALNOOR_AI_Desktop/EL_ALNOOR_AI.exe`

## ⚙️ الميزات الرئيسية للتطبيق (Key Features)

1. **المراقبة والاستماع اللحظي (Live Watcher)**: الاستماع التلقائي للمسار المشترك ومعالجة الملفات فور وصولها بدون أي تدخل بشري.
2. **شاشة المقارنة الثنائية (Dual Comparison)**: عرض صورة الفحص البشري وصورة تشخيص الذكاء الاصطناعي جنباً إلى جنب مع تحكم متزامن بالتقريب والتحريك (Zoom & Pan).
3. **قرار المشغل والتصحيح اليدوي (Operator Decision & Feedback)**:
   - زر **"مطابق"**: تأكيد مطابقة قرار الذكاء الاصطناعي للواقع.
   - زر **"غير مطابق"**: فتح نافذة تفاعلية تتيح للمشغل النقر على أي خلية في مصفوفة الـ 144 خلية (A1 إلى F24) لتحديد العيوب الحقيقية وتصحيح الذكاء الاصطناعي مع حفظها في قاعدة البيانات.
4. **سجل الفحوصات والتقارير (Inspection History & Reports)**: استعراض وفلترة كافة الألواح المفحوصة سابقاً مع إمكانية التصدير إلى تقارير HTML و PDF و CSV.
5. **سجل تدقيق الذكاء الاصطناعي (AI Audit Dashboard)**: حساب نسبة دقة النموذج الحقيقية ونسب التطابق البشري وتوثيق كافة حالات عدم التطابق.
6. **إدارة المشغلين (Operator Management)**: إضافة مهندسين ومشغلين جدد، تعديل بياناتهم، أو حذفهم، مع مزامنة القائمة العلوية تلقائياً.
7. **محاكي بث العينات المدمج (Panel Simulator)**: إمكانية بث عينات حقيقية بنقرة واحدة لتجربة المنظومة بالكامل دون الحاجة لتشغيل جهاز الفحص الفعلي.
8. **دعم كامل للغتين (العربية والإنجليزية)** مع تبديل تلقائي لاتجاه الواجهة (RTL و LTR).
